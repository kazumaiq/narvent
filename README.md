# NARVENT — IMMERSIVE ARTIST EXPERIENCE

Official conceptual digital universe for electronic music producer and synthwave/wave phonk pioneer **NARVENT** (Farkhod Musulmonov).

---

## 🌌 Creative Concept & Vision

This platform is conceived not as a standard musician portfolio, but as a cinematic, interactive digital realm inspired by the nocturnal, cosmic aesthetics of Narvent's discography.

### Visual Identity
- **Color Palette:** Deep Midnight Blue (`#050510`, `#090a24`), Obsidian Black (`#04040a`), Electric Blue (`#4f75ff`, `#7093ff`), Muted Violet (`#6b4d96`), Soft Lavender (`#c3b4e0`), Subtle Silver (`#a4a4be`).
- **Atmosphere:** Procedural volumetric nebulae, dynamic dual-layer starfields (3,000+ stars), floating stardust, reactive cursor lighting, and volumetric fog.
- **Typography:** Modern luxury serif (`Cinzel`), geometric display (`Space Grotesk`), neutral body (`Inter`), and cyberpunk catalog data (`JetBrains Mono`).

---

## ✨ Key Experience Highlights

### 1. 3D Spatial Music Archive (Centerpiece)
- **Engine:** Three.js / WebGL with custom procedural canvas cover generators and anisotropic shading.
- **Perspective & Depth:** Full discography suspended across a 3D cosmic helix.
- **Interactivity:**
  - Dynamic drag and touch orbit controls.
  - Smooth raycasting detection with cursor HUD tooltip.
  - Floating and tilting cover animations on hover.
  - Click-to-inspect modal opening detailed artwork, credits, tracklists, and streaming links.
  - Live spatial filtering (`ALL`, `ALBUMS`, `EPS`, `SINGLES`, `COLLABORATIONS`).
  - Seamless toggle to 2D mosaic grid with instant live search.

### 2. Verified Artist & Discography Database
- Real data curated from official streaming profiles (Spotify, Apple Music, YouTube Music, SoundCloud, VK):
  - **Albums:** *Genesis* (2026), *Insomnia* (2024), *Memory Reboot* (with VØJ, 2023), *Forever In This World* (2020), *Endless Way* (2019).
  - **EPs:** *Recall*, *Lights Flash*, *Ascend*, *Ocean Blue*, *Reboot*, *Corsa*, *In Our Minds* (with DVRST & Telicity).
  - **Milestone Singles:** *"Memory Reboot"* (RIAA Gold, Billboard Hot Dance #13, 310M+ streams), *"Fainted"*, *"Her Eyes"*, *"Distant Echoes"*, *"Fade Into Darkness"*, *"Way Back Home"*, *"Hypnosis"*.

### 3. Procedural Ambient Audio Synthesizer
- Built with the browser's native **Web Audio API** — 100% legal, procedural sound generation.
- Generates a subtle, analog-filtered D-minor synthwave space drone with slow LFO filter sweeps.
- Includes a live audio visualizer indicator and floating controller.
- Integrated official Spotify Player drawer for instant on-demand streaming.

### 4. Editorial Monograph ("About Narvent")
- Designed like a cyber-editorial feature with verified artist biography, milestone trajectory, and official accolades.

### 5. Verified Social Universe
- Direct portals to verified channels: Spotify, YouTube (`@NarventMusic`), SoundCloud (`musicofnarvent`), Instagram (`@narventof`), TikTok (`@narvent.music`), Telegram (`t.me/narventof`), VK (`vk.com/narventmusic`), Apple Music, and Linktree.

## 🛠️ Technical Architecture

- **Framework:** React 19 + TypeScript + Vite 8
- **3D / WebGL:** Three.js with custom procedural textures and particle systems
- **Animations:** Framer Motion + GSAP
- **Smooth Scroll:** Lenis
- **Styling:** Modular CSS system with custom variables and glassmorphism shaders
- **Icons:** Lucide React

## 🚀 Getting Started

