## Technical Stack

- **Framework:** React 19 + TypeScript + Vite 8
- **3D / WebGL:** Three.js (Gargantua Black Hole GLSL shaders, 3D spatial discography helix, procedural cosmic starfield)
- **Motion:** Framer Motion + Lenis smooth scroll
- **Audio:** Native Web Audio API ambient synthesizer + official Spotify Embed integration
- **SEO & GEO:** Schema.org `@graph` (`WebSite`, `ProfilePage`, `MusicGroup`, `Person`, `MusicAlbum`, `MusicRecording`, `FAQPage`), pre-rendered semantic HTML shell, `hreflang`, `rel="me"`, `llms.txt` / `llms-full.txt`, and IndexNow.
